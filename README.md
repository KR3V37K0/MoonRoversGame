# Moon Rovers

Лунная база ждёт грузы, а время уходит. Управляйте роверами, прокладывайте маршруты и выполняйте заказы, пока не кончились ходы.




## Как запустить

1. Перейдите в раздел [Releases](https://github.com/KR3V37K0/MoonRoversGame/releases).
2. Скачайте архив `MoonRovers.zip`.
3. Распакуйте и запустите `MoonRovers.exe`.

## Что сделано

Вы управляете лунной базой, где каждый день приносят новые заказы. У вас есть несколько роверов — у каждого свой заряд батареи и грузоподъёмность. Заказы разбросаны по карте: их нужно забирать в одной точке и отвозить в другую.

Игровой процесс строится вокруг планирования маршрутов. Вы кликаете по соседним гексам, прокладывая путь, а затем нажимаете кнопку хода — ровер проходит один гекс за раз. Каждый шаг тратит энергию, а разные участки карты требуют разного её количества.

За успешную доставку вы получаете кредиты и карточки. Карточки можно применять к роверам: одни пополняют заряд, другие временно увеличивают грузоподъёмность. Это помогает справляться с более тяжёлыми заказами.

Цель игры — набрать нужное количество кредитов за 24 хода в день. С каждым днём квота растёт, а заказов становится больше. Если уложиться не удаётся — игра заканчивается.

В игре есть:
- гексагональная карта;
- несколько роверов с разными характеристиками;
- ежедневная генерация заказов;
- система маршрутов и пошагового движения;
- карточки-усиления;
- прогрессия сложности от дня к дню.



## Логика веса и доставки

У каждого заказа есть вес. Ровер может взять только тот груз, который не превышает его грузоподъёмность. Карточки позволяют временно увеличить этот лимит.

Для выполнения заказа нужно:
1. Выбрать заказ — на карте подсветятся точки отправления и назначения.
2. Выбрать ровер, который находится в точке отправления.
3. Построить маршрут по гексам.
4. Нажимать `Сделать ход` — ровер будет продвигаться по одному гексу за раз.
5. Когда ровер достигает точки назначения — заказ считается выполненным, а награда зачисляется.

Если у ровера заканчивается энергия в пути — маршрут прерывается, и заказ не доставляется.



## Где хранятся данные

База данных SQLite (`StreamingAssets/MoonRovers.db`) содержит:
- список роверов и их характеристики;
- список баз с их названиями и координатами;
- настройки дней (количество заказов в день).
